# urleval

## Description

A marketing skill that evaluates potential URLs across multiple dimensions — memorability, cleverness, positive/negative associations, length, misspelling likelihood, competitor overlap, and relevance to the site's purpose. Grounded in academic and research-based literature on what makes a domain name effective. Also suggests alternative URLs that may perform better and are not already registered.

Input: a description of the website's purpose and a list of candidate URLs (requested interactively if not provided).
